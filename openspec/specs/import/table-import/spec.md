# import/table-import Specification

## Purpose

从 CSV、TSV 和 XLSX 批量导入收藏，通过编码、分隔符、表头和列映射自动探测减少配置。用户可预览、调整并核对跳过行，提交后按实际有效行创建持久化匹配任务。

## Requirements

### Requirement: 入口与文件
导入 SHALL 从导入队列或空库引导打开应用内向导，支持 CSV、TSV、XLSX。MusicBrainz 联系方式未配置时显示统一原因与设置入口，不能提交导入。

#### Scenario: 选择表格
- **WHEN** 用户选择文件
- **THEN** 自动进入映射和预览；XLSX 不探测编码或分隔符，多工作表文件要求选择工作表

### Requirement: 自动探测
文本文件 SHALL 优先识别 BOM，再严格验证 UTF-8，失败后尝试候选编码并按 CJK、假名、罕用字、非法字符等信号评分。分隔符比较前 50 个非空行的逗号、分号、制表符和竖线，优先非零且方差最小者；表头依据词典和首行与后续行的类型差异判断。

#### Scenario: 编码或扩展名不同
- **WHEN** 输入无 BOM 的 Shift_JIS、GB18030、Big5，或扩展名为 CSV 而内容用分号
- **THEN** 使用探测结果解析；状态行显示编码、分隔符和表头判断

### Requirement: 手动调整与列映射
编码置信度低于 80% 或未找到曲名列时，向导 SHALL 展开调整面板。文本文件可改编码、分隔符和表头；XLSX 可选择工作表，表头由解析器探测。列映射支持曲名、艺术家、专辑、年份、音轨号、碟号、时长及忽略，按中英文表头词典自动选择，用户可修改。

#### Scenario: 表头别名
- **WHEN** 表头为 Song Name、歌手名、专辑名、No.、Note
- **THEN** 分别识别曲名、艺术家、专辑、音轨号和忽略；修改映射后更新预览

### Requirement: 预览、提交与统计
向导 SHALL 预览前 20 行，分别统计字段缺失提示与真正空行或无法解析等跳过原因。具有有效映射数据但缺曲名、艺术家或专辑的行仍可提交，不因基本信息缺失跳过；完全空白的数据行不创建收藏任务。提交使用预览参数并保留原始行，关闭向导后启动 MusicBrainz 流程；可检索性不足的行进入复核。进度分母为实际入队数。

#### Scenario: 有跳过行
- **WHEN** 214 行中有 3 行完全空白，其余 211 行包括缺曲名但有其他有效映射数据的行
- **THEN** 211 行均入队，进度可达 211/211，缺曲名只提示字段缺失，3 行空白另列跳过原因

### Requirement: 导入与组织分开
导入 SHALL 仅从文件创建任务，不提供剪贴板导入、增量同步或导入时指定歌单。完成后在库内选择曲目加入集合。

#### Scenario: 导入后加入歌单
- **WHEN** 用户希望把本批曲目整理到歌单
- **THEN** 在曲库表格中多选并加入，向导不创建歌单归属
