# library/release-catalog Specification

## Purpose

将歌集共享字段、上游曲目清单和用户收藏分别管理。清单以来源及曲目标识判断是否收藏，发行组选择固定的代表版本，清单获取状态明确可查且不因日期失效；专辑封面按歌集共享，支持多张图片和同图多规格。

## 当前限制

共享字段保护、灰色行归属与歌集配套功能见 [G01、G02、G08](../../../known-gaps.md)；iTunes 长清单的数量上限见 [G12](../../../known-gaps.md#g12--清单数量上限)。

## Requirements

### Requirement: 歌集与清单身份
歌集与发行组 SHALL 在上游标识非空时以来源和标识唯一，本地歌集标题不全局唯一。清单位置以歌集、碟号、音轨号唯一，不与收藏曲目建外键；同来源和同 track 标识命中才算已收藏。

#### Scenario: 相同录音的不同位置
- **WHEN** 库内曲目与清单位置的 recording 相同但 track 标识不同
- **THEN** 该位置仍为灰色行；删除库内曲目不改变上游清单

### Requirement: 清单获取与状态
清单 SHALL 保存 none、partial、complete、failed 状态及获取时间。详情响应携带清单时一并保存；空清单或条目数少于声明总数为 partial。首次打开不完整歌集会尝试补取，设置为匹配时获取则在导入入库后执行。

#### Scenario: 详情附带清单
- **WHEN** 精确曲目详情返回全发行清单
- **THEN** 同次响应写入清单，总曲数按所有碟计算，不额外请求清单

#### Scenario: 部分或失败
- **WHEN** 返回清单被截断或请求失败
- **THEN** 分别记录 partial 或 failed；界面只显示已有曲目及补全/重试动作

### Requirement: 清单有效期
iTunes、MusicBrainz 和本地已存清单 SHALL 不因获取时间或经过天数失效，保存的 none、partial、complete、failed 状态不经日期转换。手动重新获取 SHALL 跳过本地完整状态检查及原始响应缓存，以取得新响应；缺失/不完整时仍遵守原有清单补取规则。

#### Scenario: iTunes 过期
- **WHEN** 打开已超过旧版有效期的完整 iTunes 清单
- **THEN** 直接使用已存完整清单，不因日期重取或变为 none

#### Scenario: 显式重新获取
- **WHEN** 用户手动重新获取已完整且已有缓存响应的清单
- **THEN** 访问上游取得新响应，成功后更新清单与获取时间；不以旧响应伪装重取成功

### Requirement: 代表发行
发行组 SHALL 使用 [评分规格](../../matching/confidence/spec.md)中的代表发行顺序选取清单来源。候选范围包括本地保存的整个发行组，不要求代表本身仍有收藏；名单收藏数聚合全组。

#### Scenario: 代表已无收藏
- **WHEN** CD 代表的曲目已删完而同组数字版仍有收藏
- **THEN** 保留 CD 代表及其清单，不因删除收藏切换版本

### Requirement: 共享封面
封面 SHALL 归属现有歌集实体，支持多张图片和同图多规格，并记录当前显式采用的图片。通过任意关联曲目采用后，所有指向该歌集的曲目共享更新；没有歌集时采用失败。同名不同歌集及同发行组不同发行不因名称或归组自动合并封面。专辑浏览头部使用当前代表歌集的高清封面，曲目详情使用其所属歌集的高清封面。

封面记录 SHALL 包含图片身份、文件位置、真实图片来源、类型、规格、实际宽高、来源地址和获取时间；本地图片的网络地址可空。来源为 CAA、iTunes、QQ、163、本地或无法恢复的历史未知来源，不从歌曲元数据来源推断图片来源。

#### Scenario: 一次采用多处显示
- **WHEN** 用户为某曲目采用封面
- **THEN** 同歌集所有曲目的列表与详情读取新选择，使用该歌集的专辑头部同步；清除临时缓存不删除该文件

#### Scenario: 发行边界
- **WHEN** 同发行组的 CD 和数字版属于不同歌集，而用户从 CD 歌曲更新封面
- **THEN** 仅 CD 歌集采用记录改变，数字版保持原记录；专辑聚合头部仍依据原有代表选择规则显示

#### Scenario: 图片来源独立
- **WHEN** MusicBrainz 来源的歌集采用 QQ 图片
- **THEN** 图片记录及文件名来源为 qq，歌集与歌曲匹配来源仍为 MusicBrainz
