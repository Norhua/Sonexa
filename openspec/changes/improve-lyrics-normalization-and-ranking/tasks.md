# Tasks

实施依据：[设计](design.md)、[歌词搜索 delta](specs/upstream/lyrics-search/spec.md)、[QQ delta](specs/upstream/qqmusic/spec.md)。本清单未开始执行；采用最新确认的「每源 Top 3 预取 → 内容综合排序 → 翻译加分、罗马音较小加分 → 候选卡片显示两种通道状态」。默认使用离线测试，真实网络必须显式启用；较小的既有 probe 预算优先，不能自动抬高网络验证授权上限。

- [ ] 7.3 在实际发送层接入歌词上下文预算与停止策略：每源轮次 60 秒/16 次发送，候选最多 40 秒；重试、重定向和回退全部记账，429/认证/TLS/超限不继续该来源；计数/假时钟测试覆盖第 17 次被拒、截止取较早值、其他用途无预算时行为不变、其他来源不受阻断。
- [ ] 7.4 支持来源结束后的人工单候选获取与可允许重试（40 秒/8 次发送），不启动邻项预取；测试原轮次到期后已完成文档仍可读、未预取项显式获取后加入相同综合排名、来源仍受限制时不可绕过、停止项最终离开 loading。
- [ ] 7.5 为文档增加版本和成功预览确认，预取不设置 PreviewedVersion；测试“已预取未预览直接采用”拒绝、确认错误版本拒绝、预览复用不出网、重新获取清除旧批准及修订冲突保持旧文件，排序键不可替代会话权限。
- [ ] 7.6 限制每来源会话 32 MiB/进程 128 MiB 的保留文本与行投影，摘要事件不广播全文，关闭释放资源；注入小预算测试验证超额明确拒绝、不截断或驱逐正在预览版本、部分成功仍保留，并更新架构文档中的池、预算、事件及会话权限边界。
