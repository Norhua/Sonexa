# Spec Delta

## MODIFIED Requirements

### Requirement: 手动歌词翻译与逐字获取
独立歌词搜索的自动预取与显式获取 SHALL 共用 `music.musichallSong.PlayLyricInfo.GetPlayLyricInfo`，一个 `musicu.fcg` 请求批量获取逐字和普通歌词两块，明确 `songMid`、`trans=1`、`roma=1`、`crypt=0` 和 `qrc=1/0`；不为取得歌词额外查询数字歌曲 ID。普通原文和翻译独立解码 Base64 与实体，兼容响应声明的加密内容；QRC 和罗马音仍可能为十六进制密文，解码失败不得伪报上游未提供。每个通道在解码后按实际内容区分 QRC 容器、逐字正文、普通 LRC 与纯文本，不仅凭请求标志或通道名称断定格式，不重复解码。原文、翻译、罗马音及逐字状态按[歌词搜索](../lyrics-search/spec.md)分别报告，并用于候选卡片和综合评分；未提供时不调用翻译或音译生成服务。

#### Scenario: 普通接口没有翻译
- **WHEN** 旧接口返回成功但翻译为空，新端点提供翻译
- **THEN** 使用新端点已取得的翻译，不把旧接口未提供描述为解析失败；新端点同样未提供时明确显示缺失，不声称翻译已获取

#### Scenario: 显式逐字与普通批量请求
- **WHEN** QQ 候选进入该来源的 Top 3 预取，或用户显式获取尚未取得的候选
- **THEN** 以歌曲 MID 在同一请求取两种歌词及上游附加通道，消费同一共享配额和对应请求预算；HTTP 成功后仍分别校验顶层与请求块业务状态，普通块可用时不因逐字块失败丢弃正文

#### Scenario: 选中已预取 QQ 候选
- **WHEN** 用户选择已经成功预取的 QQ 歌词候选
- **THEN** 从会话复用同一文档、通道状态及评分，不重复请求 musicu 或旧接口；预取不自动获得采用权限，成功预览后才允许明确采用

#### Scenario: 附加通道实际为 QRC
- **WHEN** 翻译或罗马音解密后带 QRC 容器及词时间，而不是普通 LRC
- **THEN** 按实际格式转换并保留可用文字与真实时间，不将原始容器或数字括号显示为正文；一个附加通道失败不改变其他通道状态

#### Scenario: 请求逐字但仅返回逐行
- **WHEN** 逐字请求成功，解码后只有有效逐行 LRC 或无时间的原文
- **THEN** 保留真实格式作为可预览原文，逐字显示上游未提供，不因请求了 QRC 就声称有逐字信息

### Requirement: 在线 QRC 转换与回退
在线 QRC SHALL 经十六进制解码、QQ 变体 DES 和有界 zlib 解压，读取 XML 的 `LyricContent` 或逐字正文；按上游绝对毫秒时间转换为增强型 LRC 行及词起止标签，校验行/词时间、顺序与边界，保留空词时间间隔与普通署名行。容器读取支持实际歌词轨标签，不将多轨串接为同一份正文；仅在容器边界可唯一确定时容忍歌词属性中的未转义引号，无法确定完整边界时明确失败，不输出被截断内容。没有上游逐字时间时不得按字数或行号推造时间。响应、解压及转换大小与取消限制遵循[歌词搜索](../lyrics-search/spec.md)。此能力不扩展到本地 QRC 文件导入或播放器同步高亮。

无 QRC 时 SHALL 使用同批普通 LRC；QRC 解析失败时显示逐字失败并尝试普通块，仍无可用原文且未触发停止条件时回退旧 `fcg_query_lyric_new.fcg`，兼容其 JSON/JSONP 包装、Base64 与实体编码并检查业务错误。回退保留新接口已取得的翻译/罗马音并显示警告，两条路径都无法取得可用原文时不可保存；可选通道失败不直接丢弃可用原文。不绕过认证、限流或证书校验，取消、超限及上述限制按歌词搜索规则停止后续请求。

#### Scenario: 逐字内容转换
- **WHEN** 上游 QRC 包含绝对毫秒词时间、空词间隔和署名行
- **THEN** 增强型 LRC 保留实际词起止与间隔、署名正文，校验失败不输出猜测时间；预览和采用保留转换结果

#### Scenario: 逐字失败但普通歌词可用
- **WHEN** QRC 解码或时间校验失败，而同批普通 LRC 可用
- **THEN** 预览普通 LRC 并显示逐字失败，翻译/罗马音独立保留；没有 QRC 与 QRC 解析失败不使用相同状态

#### Scenario: 旧接口回退保留附加通道
- **WHEN** 新端点只取得翻译或罗马音，旧接口取得可用原文
- **THEN** 合并已取得的通道并报告回退；若旧接口同样失败则不给可采用文档，不清除当前歌曲的既有歌词

#### Scenario: 容器中的引号与多轨
- **WHEN** QRC 歌词属性含可确定边界的字面双引号，或容器中有多个歌词轨
- **THEN** 保留所选歌词轨中完整引号正文而不截断，不吞入下一轨或 XML 标签；边界不明确时走解析失败及普通歌词回退

#### Scenario: 正文括号不是词时间
- **WHEN** QRC 正文含普通圆括号、空格和 emoji，周围有合法数字词时间标记
- **THEN** 仅转换合法时间标记，完整保留这些文字，原始文本与可读预览均不丢词
