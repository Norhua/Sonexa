# Spec Delta

## MODIFIED Requirements

### Requirement: 注释分类与查询主体
注释 SHALL 按 CV、版本、翻译提示、歧义说明、文字系统差异及保守回退顺序分类。版本内容保留；译名或 CV 可提供备选文本，feat./ft./with 作为附加艺术家而非版本。查询主体可去除末尾截断省略号、未闭合注释及非版本注释以扩大召回，结果为空时保留可用原文。查询简化不构成字段等价证明，自动身份判断须使用保留原文、注释类型及不确定性的输入证据。

#### Scenario: 版本与译名
- **WHEN** 输入 That Girl (DJLIU Remix) 或夕立（驟雨）
- **THEN** 前者保留版本查询，后者可分别使用夕立和驟雨；两者均保留原始输入用于评分和证据核验，不因查询结果相同就认定相同 track

#### Scenario: 未知括号可搜索但不自动等同
- **WHEN** 括号内容无法可靠识别为译名、版本或署名信息
- **THEN** 允许使用剥离形式召回，同时保留未知内容；不能仅凭剥离后相同就自动接受、跳过或归并待办

## ADDED Requirements

### Requirement: 三字段异写证据
元数据输入识别 SHALL 对曲名、艺术家和专辑提供一致的形式规范化及可靠异写证据。完整字段、可识别的译名/读音或可靠来源别名可作为备选写法，并保留依据；文字系统差异本身只产生候选别名，不证明任意两段文字互为翻译。外层原名完整相同且内层被可靠识别为附加译名时，可在其他必要证据成立后消除该格式差异；无法建立对应的纯译名须保持未知，不调用翻译服务猜造身份。

#### Scenario: 有译名与无译名的两份表格
- **WHEN** 两行分别使用原名和原名加可识别译名，曲名、艺术家、专辑的有效名称均对应且版本及其他已给条件一致
- **THEN** 产生一致的目标识别依据，不因括号差异额外创建收藏或复核问题

#### Scenario: 括号内为上游采用的原名
- **WHEN** 输入为译名加可验证的原名，候选采用该原名
- **THEN** 允许用可靠内层原名参与匹配，并在判断说明中标明使用了异写证据

#### Scenario: 纯译名没有可验证对应
- **WHEN** 两行只有不同语言的名称且没有共同名称、可靠别名或上游证据
- **THEN** 不仅凭语言不同就断言等价，保留匹配不确定性

### Requirement: 录音版本与发行限定
元数据自动身份比较 SHALL 分别保留歌曲的录音版本限定与专辑的发行限定，覆盖括号内外及已支持的等价写法。版本比较包括限定内容而非仅关键词：不同 remix 作者、live 场次、编辑版、伴奏、重录及重制年份不得因同含 Remix 或 Live 而等同；豪华版、限定版等不得作为普通翻译删除。无法解释的版本内容保留原文并阻止仅靠剥离建立自动等价。

#### Scenario: 两种 remix
- **WHEN** 曲名分别为 Song (A Remix) 与 Song (B Remix)
- **THEN** 即使都含 Remix 且歌曲主干相同，仍保留版本冲突，不自动归并或跳过

#### Scenario: 专辑附加信息区分
- **WHEN** 比较 Album（中文译名）与 Album，或 Album (Deluxe Edition) 与 Album
- **THEN** 前者仅在译名证据成立时可等价，后者保留发行限定差异，不自动视为同一已指定版本

### Requirement: 署名身份与参与信息
元数据自动身份比较 SHALL 保留输入明确给出的角色、组合成员和合作参与信息。CV 声优、主署名或附加艺术家可帮助召回，但不因声优相同就把不同角色演唱视为同一版本，也不因主歌手相同就忽略明确不同的合作阵容。艺术家列确实使用发行署名或团体署名时，只有明确的来源关系及专辑/位置证据才能解释差异，不把无法解释的冲突当作缺失。

#### Scenario: 同声优不同角色
- **WHEN** 两候选为角色 A(CV.X) 与角色 B(CV.X)，输入明确给出角色 A
- **THEN** 声优 X 相同只作为召回证据，角色 B 不进入该输入的自动候选集合

#### Scenario: 发行署名与歌曲署名
- **WHEN** 表格艺术家填专辑团体，候选歌曲署名是成员，来源明确给出对应团体发行署名且专辑及曲目位置对应
- **THEN** 可用结构化证据解释差异，而不是一律丢弃或仅凭歌集相同忽略任意艺术家冲突

### Requirement: 截断与缺失信息
输入证据 SHALL 区分完整、截断、缺失和解析失败。截断前缀只能证明与完整文本相容，不能标成精确相等；必须有区分目标的有效内容并结合歌曲、署名和目标发行资料才可消歧。只剩通用前缀或缺少关键版本尾部时不得自动确定。时长统一为可比较单位，年份和位置保留缺失与来源语义，不用默认零或第一碟填补。

#### Scenario: 特典 CD 截断名
- **WHEN** 专辑输入为冴えない彼女の育てかた 第4巻 特典C...，候选包含该特典 CD 和名称不同的歌曲合集
- **THEN** 将特典 CD 记为有区分力的截断相容候选，合集不因共享作品名前缀被当作相容；补足必要资料后才可选定具体 track

#### Scenario: 截断在版本差异之前
- **WHEN** 输入只剩 Album...，候选是多个不同年份或限定版本
- **THEN** 保留歧义，不以共有前缀或本地只收藏一版为充分证据

#### Scenario: 时长格式差异
- **WHEN** 两行时长分别为 10:20 和明确单位的等值秒数或毫秒数
- **THEN** 比较相同的时长值；无法解释的单位保持未知，不参与精确相同输入证明
