# Spec Delta

## MODIFIED Requirements

### Requirement: 导航与页头
侧栏 SHALL 依次显示独立搜索入口，以及资料库、歌单、标签、任务四组；资料库包含最近添加、全部曲目、艺术家、专辑，任务包含导入队列和复核队列。分组区域可滚动，设置固定在底部；全局提示固定在设置正上方，不随导航滚动，不占主内容顶部。提示按侧栏宽度换行，过长内容内部滚动；设置入口始终可见，无提示不留占位。页头高 48px；侧栏顶部预留 macOS 窗口按钮与拖动区域，输入和操作按钮不触发拖动。任务区区分按原始行统计的导入进度和按独立问题统计的复核待办。

#### Scenario: 导航与新增
- **WHEN** 用户浏览侧栏或聚焦歌单、标签标题行
- **THEN** 二级项悬停或聚焦时显示新增按钮，无悬停能力的设备始终显示；二级项缩进，空提示与图标起点对齐

#### Scenario: 任务进度
- **WHEN** 导入运行或有待复核问题
- **THEN** 侧栏显示当前批次已处理原始行数/实际入队数及进度条；复核徽标采用全部批次独立待选与失败问题汇总，不用单批 review 行数覆盖。旧响应不覆盖新事件，详细状态和日志位于任务页

#### Scenario: 全局提示优先级与操作
- **WHEN** 出网禁用、离线或普通错误需要全局提示
- **THEN** 均显示在侧栏设置上方，按出网禁用、离线、普通错误的优先级呈现；禁用原因保留上游设置跳转，普通错误可关闭，持续状态不可关闭，页面局部提示不受此位置约定影响

### Requirement: 共享候选表格
元数据搜索与复核 SHALL 共用来源、封面、标题、艺术家、歌集及类型、时长、音轨、年份、载体、国家、展示置信度和动作列。能力声明控制可选列。搜索动作是加入/已在库中，复核候选动作是接受/跳过，不再有合并。只有精确来源 track 绑定及发行关系成立时显示本地徽章和已在库中/跳过；ISRC、Recording 或文本相似不能决定这些状态。另行显示关键自动判断说明，不把展示分数当作正确版本概率。

#### Scenario: 来源与缺失字段
- **WHEN** 候选精确已在本地或曲序信息不全
- **THEN** 精确已有候选可同时显示本地与上游徽章；音轨按已知值显示 n/m、n/—、—/m 或 —，缺失字段不补猜测值

#### Scenario: 两条同 ISRC 的候选
- **WHEN** 只有特典 CD 的 track 已收藏，合集 track 与其共享 ISRC
- **THEN** 复核分别显示跳过和接受，搜索分别显示已在库中和加入；合集不会因为有关联录音而丢失添加入口

#### Scenario: 收藏变更刷新动作
- **WHEN** 某精确候选被收藏、删除或换绑
- **THEN** 相关搜索和复核视图按当前身份更新徽章及按钮，不因候选正文未变而保留旧本地状态，不需要重新发起上游搜索

## ADDED Requirements

### Requirement: 问题数与行数展示
复核页 SHALL 展示独立问题数及待选、失败分项，并标注涉及的原始行数；多行问题可展开批次、行号和原文。导入队列按各批次原始行显示新增、已存在跳过、待复核及失败等状态，跳转复核时说明涉及的问题数；归并不改变导入进度分母。归并、拆分或单行完成后，即使全局问题数相同，也应更新来源及批次统计。

#### Scenario: 两批相同问题
- **WHEN** 两个批次各有一行对应相同复核问题
- **THEN** 侧栏及复核页显示一个待办并标注两行来源，两批导入记录各显示一行待复核，不显示两份要求重复操作的卡片

#### Scenario: 处理后计数
- **WHEN** 一个两行问题接受后新增一个 track
- **THEN** 复核问题消失，全局待办减少一，各批次分别显示真实新增或已存在跳过，不显示新增两首
