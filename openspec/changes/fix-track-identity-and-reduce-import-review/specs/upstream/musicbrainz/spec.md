# Spec Delta

## MODIFIED Requirements

### Requirement: 查询与结果粒度
有曲名的组合查询 SHALL 使用 recording AND (release OR artist OR artist alternates)，仅包含已填条件，艺术家备选最多两个；仅曲名级不带辅助条件。搜索结果按录音、发行、碟、位置展开，使用响应中的真实 track 标识；没有位置时保留明确标注为未解析的合成候选。相同录音在不同发行或不同位置展开为不同候选，不以 ISRC 或 Recording 去掉其他可收藏版本。

#### Scenario: 歌集和艺术家条件
- **WHEN** 曲名和歌集相符，但录音署名与输入不同
- **THEN** 可通过歌集条件返回候选，再由统一匹配规则判断展示及自动资格

#### Scenario: 搜索响应解析
- **WHEN** 响应使用 media.track 或 media.tracks
- **THEN** 均解析位置及已知曲序、载体等字段；纯数字 number 可回退为位置，A1 等编号不推断为数字位置

#### Scenario: 不同专辑的同录音
- **WHEN** 同一 recording 出现在特典 CD 和合集
- **THEN** 返回各自 track、发行和位置，后续已收藏状态分别判断，不只保留已收藏版本

## ADDED Requirements

### Requirement: 合成候选解析为真实位置
MusicBrainz SHALL 在未解析候选被选作新收藏或自动目标前，根据明确的目标发行读取可用清单，并用 recording、输入位置及完整性证据解析真实 track。解析结果必须属于原目标发行；相同发行多个位置符合、清单不完整且无法排除其他位置、或目标未找到时返回歧义或资料不足，不选第一首、不伪造标识。得到真实位置后重新执行自动证据和精确已收藏检查，合成标识不成为新的收藏绑定。

#### Scenario: 唯一真实位置
- **WHEN** recording@release 候选的目标发行完整清单只有一个符合输入的 recording 位置
- **THEN** 返回该真实 track 标识及位置，后续按真实 track 判断接受或已存在跳过

#### Scenario: 同发行重复收录
- **WHEN** 同一 recording 在发行中有两个 track，输入没有能区分的位置证据
- **THEN** 保留两个真实候选供复核，不按已收藏其中一首、顺序或最近时长自动替代

#### Scenario: 清单局部唯一
- **WHEN** 已取得的部分清单中只有一个匹配位置，但缺失部分仍可能包含相同录音
- **THEN** 不声称唯一解析，获取必要资料或报告资料不足

#### Scenario: 身份展开后精确已存在
- **WHEN** 合成候选解析得到的真实 track 已被收藏
- **THEN** 按精确身份显示或执行跳过，不另外保存一条合成身份收藏

### Requirement: 决策资料获取有界且不创建收藏
用于身份和版本判定的 MusicBrainz 资料获取 SHALL 只针对当前候选涉及的必要发行，在同次解析内复用同发行响应，遵循已有缓存、共享限流、重试、出网门禁及取消。不得为了寻找有利版本遍历整个 release group，不得在资料预览时创建曲目、发行或正式成员。错误、未知和无结果须区分，失败不得被当作已确定不存在竞争候选。

#### Scenario: 多候选属于同一发行
- **WHEN** 同次输入解析的多个候选需要同一发行的摘要或清单
- **THEN** 复用同份成功响应，不为每个候选重复获取，不增加收藏或发行成员

#### Scenario: 必要请求失败或被取消
- **WHEN** 必须补取的位置资料请求失败、被禁止出网或用户取消
- **THEN** 保留原输入及未完成状态并说明原因，不跳过输入、不使用部分结果伪造唯一 track
