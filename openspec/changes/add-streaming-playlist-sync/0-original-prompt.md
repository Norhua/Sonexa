## 用户原始输入
实现流媒体平台绑定和同步功能，作为上游的一个能力：
1. 目前实现 QQ 音乐 和 spotify
2. 绑定的对象是用户在流媒体平台上的歌单
3. 当前只实现从上游同步，不支持在 Sonexa 中向同步歌单中添加和删除歌曲。也就是说我们只需要读取流媒体歌单的内容就好
4. 对于 QQ 音乐歌单，可以直接在现有 qqmusic.Provider 上实现歌单接口
5. 但对于 Spotify 我们需要使用 python 库 SpotifyScraper
6. 对于 3，4, 我都实现过 demo 位于./tmp/demo/ 下。注意 demo 只用来告诉你有走的通的路，不要照搬其中实现，具体的实现都要考虑 sonexa 现状。

对于接下来的描述存在两个可能混淆歌概念我需要声明：
1. 导入：指歌曲走完了导入流程（导入队列自动匹配、复核队列手动接受或选择无需绑定）。处于导入队列或复核队列中的歌曲均属于未导入（不在同步歌单页面中
   展示）。
2. 加入曲库 / 已入库：指歌曲进入了用户的“我的音乐库”，会在「全部曲目 / 最近添加 / 艺术家 / 专辑」中展示并参与全库导出。同步歌单导入完成的歌曲初始
   仅存在于同步歌单，不自动进入曲库。

对于相关流程的设计如下：
1. 用户选择平台然后输入歌单链接/歌单 id，获取到歌单。这里可以为歌单添加别名，未指定时使用流媒体歌单名
2. 对于选择的歌单，首先获取到所有歌曲信息 (曲名，署名艺术家，专辑名，时长)，这些信息将被存入数据库的相关表。这些表用于记录歌单/歌曲状态，这样每次
   同步后只需要处理增量数据而不需要重新让整个歌单进入导入流程
3. 为了统一管理，进入表中的歌曲将通过导入流程 (导入队列，复核队列)，但是并不加入曲库而是只存在于”歌单”。
4. 对于 3，我们需要在 track 表中添加新的字段 (比如 in_library) 用来标识歌曲是否入库，对于没有入库的歌曲不在「全部曲目 / 最近添加 / 艺术家 / 专辑」
   中展示。同时，我们需要修改导入队列前端，在导入队列页面重新搜索下方的”恢复原始信息”“无需匹配””移除队列”按钮的同一行的最右侧写上导入位置（例如
   ”to 音乐库”，”to 流媒体平台歌单名称”）对于流媒体平台歌单需要展示为橙色
5. 对于 2，获取到的信息将存入数据库，同时数据库还有字段用来存储歌曲在流媒体歌单和本地的状态。流媒体歌单状态用来标识这一项是否还存在于上游流媒体歌
   单，本地状态用来标识这首歌是还未导入 (在复核队列也属于未导入)，还是已导入。
6. 对于已经不存在上游且未导入的歌曲将被直接从表中删除 (如果在复核队列，也将被从复核队列删除)，对于已经不存在上游但已导入的歌曲将被显示为灰色
7. 对于同步歌单前端页面存在以下元素
    a. 在 AppSidebar.vue 的「歌单」下方新增独立的「同步歌单」分组，标题右侧 + 按钮用于打开“绑定同步歌单”弹窗（选择平台 + 输入歌单链接/ID），右键
   支持删除同步歌单。
    b. 同步歌单中只展示已经导入的歌曲
    c. 刷新 (图标位于同步歌单页面最上方歌单名称后): 用于重新获取上游歌单中的内容，然后修改相关表。点击刷新后将会出现一个弹框，用于显示上游变化 (
   新增了哪些，删除了哪些)
    d. 表格增加一列名称为已入库 (只在表头右键菜单显示，用于用户选择是否显示，表头不显示只留出一列)，显示为一个绿色的圆中有个对勾，当这首歌已加入
   曲库显示，没有加入曲库则不显示
    e. 右键菜单中提供”添加到我的音乐库”选项，对于多选时右键点击”添加到我的音乐库”将会弹出提示哪些歌曲将被添加到音乐库，哪些音乐库中已经存在

   本期是否仅支持无需登录即可读取的公开歌单？不做账号登录、OAuth 或 Cookie 配置，私密/受限歌单明确报错。
2. Spotify 的 Python 环境
   希望随 Sonexa 打包独立运行环境，用户无需安装 Python，还是本期允许用户自行安装 Python 和 SpotifyScraper？这会明显影响构建和交付范围。
3. 跨歌单复用歌曲
   建议：可靠判重为同一首本地曲目时，多个同步歌单复用同一个 track，但各自维护上游存在状态；加入曲库后，各歌单的“已入库”标记同步更新。是否符合预期？
4. 删除同步歌单 / 从曲库删除歌曲
   建议规则：
    - 删除同步歌单：清理其待导入任务和关联；保留已入库或被其他歌单引用的歌曲，仅清理无其他归属的未入库歌曲。
    - 从“我的音乐库”删除歌曲：若仍被同步歌单引用，只取消入库状态，同步歌单中的已导入歌曲仍保留。
      是否采用？
5. 手动“移除队列”后的刷新行为
   对同步歌单的待导入歌曲点击“移除队列”后，下次刷新是否应重新入队？建议记为主动忽略，连续刷新不重新入队；若上游先删除、之后重新添加，再视为新增。
