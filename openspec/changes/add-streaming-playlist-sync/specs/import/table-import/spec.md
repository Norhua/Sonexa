# Spec Delta

## MODIFIED Requirements

### Requirement: 导入与组织分开
表格导入 SHALL 仅从文件创建以音乐库为目标的任务，不提供剪贴板导入或在文件向导指定歌单；新建曲目完成后入库，可靠重复跳过遵循全 track 判重且不隐式入库。完成后在库内选择曲目加入普通集合。流媒体增量输入由独立同步歌单入口创建，使用同一导入处理流程但以同步歌单为目标，不能把普通歌单当作导入目的地。

#### Scenario: 导入后加入歌单
- **WHEN** 用户希望把本批曲目整理到歌单
- **THEN** 在曲库表格中多选并加入，向导不创建歌单归属；被跳过的未入库曲目须先显式加入音乐库

#### Scenario: 不同来源共用处理
- **WHEN** 表格与同步歌单同时提交有效输入
- **THEN** 均进入统一队列，保留各自来源和目标，不把同步输入伪装为临时 CSV 文件

## ADDED Requirements

### Requirement: 导入批次目标与统计用语
导入批次列表 SHALL 展示导入位置，音乐库目标显示“to 音乐库”，同步目标显示橙色“to 歌单显示名”；合并跨目标输入不丢失各自目标。新建曲目成功称为完成导入，不把同步专属成功计作已入库；重复跳过继续计 skipped，并说明复用本地曲目。

#### Scenario: 同步批次完成
- **WHEN** 同步批次成功导入五首且未执行入库
- **THEN** 日志/统计说明五首完成导入到同步歌单，不宣称新增五首音乐库曲目
