# Spec Delta

## MODIFIED Requirements

### Requirement: 候选本地识别
候选 SHALL 只按来源 + track 标识查询整个 track 表的当前绑定，精确命中显示本地与上游徽章；不通过 ISRC 或无绑定文本命中标注本地，也不生成疑似本地候选。ISRC 仅为 recording 级搜索线索，不证明收藏或发行位置身份；离线导入判重不为候选建立额外上游绑定。本地徽章不表示已入库，动作另按 in_library 判断：复核精确命中仍可跳过，搜索仅对已入库项显示已在库中，未入库项允许显式入库并复用本地身份。

#### Scenario: ISRC 与文本命中
- **WHEN** 来源 + track 标识未命中，但 ISRC 相同或无绑定收藏文本相同
- **THEN** 候选仍只显示上游徽章，不标注本地或疑似重复，不以此提供跳过动作

#### Scenario: 精确绑定
- **WHEN** 候选来源和 track 标识与当前已入库曲目完全一致
- **THEN** 显示本地及上游徽章；复核候选提供跳过，搜索候选显示已在库中并可跳转

#### Scenario: 仅同步歌单持有
- **WHEN** 精确绑定曲目存在但 in_library 为 false
- **THEN** 仍显示本地徽章，复核跳过复用它且不入库；搜索不误报已在库中，可明确添加到音乐库

### Requirement: 已入库输入证据
导入判重 SHALL 扫描整个 track 表，不论 in_library 为真或假，分别比较当前值和有效快照。证据优先级为有效历史确认、唯一精确来源 track 候选加上下文、完整曲名/署名/专辑严格等价。每条输入须独立支持同一个唯一最高证据目标，不能借邻居或“只有一个已在库”消歧；前置检查不依赖默认上游或网络成功。

无确认关系时 SHALL 保护录音/发行版本、已知位置及超过 3 秒的时长冲突，缺字段不加证据，截断异写不算完整精确。候选池精确身份唯一且已绑定时，严格曲名和相符专辑可补证，可比较艺术家不能冲突。专辑简称还须完整署名可靠一致及有意义的完整词边界连续短语，不能用任意子串、相似度或 Album/Soundtrack 等泛称。Original Soundtrack/Original Game Soundtrack 为专辑类型，不算录音 Original 版本冲突。

快照 SHALL 同时核验 track、其所属 release、当前 release 及 release snapshot 身份；不得混搭当前值与快照的有利字段，当前明确位置/时长冲突仍否决。重复仅结束导入并记录本地曲目及有效同步目标关联，不改字段、新增绑定、切换主来源或改变 in_library。入库状态变化不使仍有效的输入确认失效。

#### Scenario: 跨来源离线排除
- **WHEN** 输入三字段与 QQ 本地曲目当前值或有效快照严格等价，且整个 track 表目标唯一、无冲突
- **THEN** 即使默认来源为 MusicBrainz 且没有搜索结果也直接 skipped，不修改 QQ 绑定或曲库归属

#### Scenario: 精确绑定支持专辑简称
- **WHEN** 唯一精确 track 候选已绑定，曲名和完整署名可靠相符，专辑分别为 LINES 与 Trinoline Original Soundtrack ~LINES~
- **THEN** 可用有意义的完整词边界简称确认重复；无精确绑定、泛称或版本/位置冲突时不能套用该规则

#### Scenario: 不拼接事实或借邻居消歧
- **WHEN** 匹配需要当前曲名配快照专辑才能成立，或某被吸收输入仍指向多个等强目标
- **THEN** 不自动跳过，即使另一输入已唯一命中或某候选已在库

#### Scenario: 未入库同样参与消歧
- **WHEN** 一条已入库和一条未入库曲目都满足相同最高级证据
- **THEN** 保持歧义，不能过滤未入库项后声称唯一命中

### Requirement: 重复入库处理
显示候选时 SHALL 查询本地身份及曲库归属；搜索中已入库曲目显示已在库中，有本地标识时可跳转。交互明确加入相同来源同一标识时返回已有曲目，未入库时只更新归属，不创建第二条。自动导入须在最终写事务重做本规格的输入证据检查；即使其他来源刚保存为未入库曲目也重新判断，确认则返回已有曲目并 skipped，不改变入库状态。现存精确身份不能通过输入核验时返回 plan_stale，不以唯一约束绕过核验。

#### Scenario: 并发加入
- **WHEN** 搜索和复核几乎同时加入同一来源同一标识
- **THEN** 后一次返回已有曲目身份，不显示唯一键错误；最终是否入库由明确入库动作决定，同步导入不取消已入库状态
