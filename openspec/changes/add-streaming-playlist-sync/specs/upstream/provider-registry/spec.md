# Spec Delta

## MODIFIED Requirements

### Requirement: 接口与注册表
每个音乐元数据上游 SHALL 提供标识、显示名、能力、速率、配置检查、曲目搜索、候选快照转换、精确详情补全和自身身份解析校验；支持的发行摘要、版本浏览及封面能力按声明提供。元数据注册表包含 MusicBrainz、iTunes 和 QQ 音乐，搜索、复核与编辑来源选择按设置顺序读取注册表。来源的地区需求、标识说明与链接解析规则对调用方统一提供。导入自动匹配继续只使用 MusicBrainz。封面搜索另行提供 CAA、iTunes、QQ、163 的来源列表；[歌词搜索](../lyrics-search/spec.md)独立提供网易云音乐、QQ 音乐、酷狗音乐，不登记酷我；公开歌单读取独立提供 QQ 音乐和 Spotify。各来源仅需提供其登记的业务能力，封面、歌词和歌单来源无需提供元数据功能，也不自动进入元数据注册表或导入来源。各业务的来源展示、合法性校验及请求分发 SHALL 使用同一份已登记能力信息，不把未提供能力伪报为成功空结果。

#### Scenario: 注册来源
- **WHEN** 程序登记具备统一契约的新音乐元数据来源
- **THEN** 搜索、复核和编辑选择列表显示该来源，身份说明和可用字段由其声明提供

#### Scenario: QQ 音乐元数据上游
- **WHEN** 用户在上游搜索、复核改搜或编辑中选择 QQ 音乐
- **THEN** 按 QQ 音乐规则搜索和精确补全，使用相同快照与准入契约，导入自动匹配来源不变

#### Scenario: 封面专用来源
- **WHEN** 163 注册为封面搜索来源
- **THEN** 封面搜索能选择它，音乐元数据来源列表不增加该来源

#### Scenario: 歌词专用来源
- **WHEN** 用户打开歌词搜索来源列表
- **THEN** 可多选三个默认歌词来源，不要求其提供元数据能力，元数据搜索、复核、编辑与自动导入的来源范围不变

#### Scenario: 只提供单一能力
- **WHEN** 应用接入一个只提供歌词搜索和获取的来源
- **THEN** 该来源可参与现有歌词查询、预览与采用流程，不要求元数据或封面实现，也不出现在未登记能力的选择列表中

#### Scenario: 来源与能力不匹配
- **WHEN** 请求一个未登记的来源，或向歌词业务指定仅有封面能力的来源
- **THEN** 返回明确的来源或能力不可用错误，不发送上游请求，不伪装成没有歌曲或没有歌词

#### Scenario: Spotify 仅歌单能力
- **WHEN** Spotify 已登记为公开歌单来源
- **THEN** 绑定列表能选择它，元数据搜索、复核搜索、编辑匹配和自动导入来源不增加 Spotify

## ADDED Requirements

### Requirement: 歌单消费能力与装配
歌单业务 SHALL 声明自身只读输入、完整快照及错误契约，由各上游实现并通过应用装配注入。QQ 的歌单能力复用现有上游实例，Spotify 只提供歌单能力；业务、存储和前端不按平台 ID 解释原生字段、构造请求或操作运行环境。能力列表同时提供可用性，运行环境异常的来源明确报不可用，不静默消失或返回空结果。

#### Scenario: 单能力替身
- **WHEN** 测试装配一个只提供歌单读取的替身
- **THEN** 可完成绑定、同步及队列投递而无需元数据、封面或歌词实现，业务不导入具体上游

### Requirement: 歌单平台配额与生命周期
歌单所有实际请求 SHALL 检查应用当前出网门禁、响应取消并计入平台共享配额。QQ 歌单分页、补取及允许的有限重试与既有 QQ 元数据、封面、歌词共用同一桶；Spotify 使用进程级独立平台桶，辅助程序重启不能重置配额。歌单请求不读写原始响应缓存；限制类错误停止本轮，不执行通用六次重试或接口轮换绕过限制。

#### Scenario: QQ 合计限速
- **WHEN** 歌单刷新与 QQ 元数据、歌词同时请求
- **THEN** 合计仍受同一个 QQ 设置值和突发容量约束，不为新能力建立额外额度

#### Scenario: 能力更新与退出
- **WHEN** 设置更新或应用退出时存在歌单工作
- **THEN** 新操作使用新装配快照，既有任务仍受当前门禁和共享配额控制；退出取消所有歌单工作后再关闭数据存储
