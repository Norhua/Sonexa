# Spec Delta

## Purpose

提供独立于元数据搜索的公开流媒体歌单读取能力，使 Sonexa 能通过平台及链接或标识取得可信的完整歌单快照。统一上游身份、顺序、基础信息及失败语义，避免将访问限制或分页缺失误判成用户删歌。

## ADDED Requirements

### Requirement: 公开歌单只读访问
系统 SHALL 支持匿名可读取的 QQ 音乐和 Spotify 公开歌单，通过所选平台的歌单链接或 ID 获取内容；不要求用户登录、OAuth、开发者密钥或 Cookie。能力仅提供读取，不提供上游歌曲添加、删除、重排或歌单修改。输入必须归属于所选平台，不访问任意用户地址。

#### Scenario: 支持的输入
- **WHEN** 用户提交 QQ 数字歌单 ID、QQ 官方歌单详情链接，或 Spotify 歌单 ID、官方 playlist 链接
- **THEN** 解析为平台内规范歌单身份；不影响身份的分享参数不参与绑定去重

#### Scenario: 私密或无效输入
- **WHEN** 输入为其他平台地址、非歌单链接，或歌单需登录、已失效、受限制
- **THEN** 返回可理解的输入或访问错误，不创建空歌单、不引导提交凭据、不尝试绕过限制

### Requirement: 歌单快照字段与身份
读取结果 SHALL 包含规范歌单身份、上游名称、获取时间、有序条目及完整性依据。歌曲条目包含稳定平台歌曲身份、可区分重复出现的条目标识、曲名、署名艺术家、专辑名和毫秒时长；如实表示缺失字段，不用演唱者替代署名，不生成播放地址。平台身份用于同步，不自动成为 Sonexa 的元数据匹配绑定。

#### Scenario: 同曲重复出现
- **WHEN** 同一平台歌曲在歌单中出现两次，或歌单发生重排
- **THEN** 保留两次出现及顺序；已存在条目不会仅因位置变化被整体删除重建，位置不作为跨歌曲身份

#### Scenario: 字段未知
- **WHEN** 普通歌曲具有稳定身份但缺少某个基础字段
- **THEN** 保留条目和缺失状态供后续导入/复核，不使用占位名称或另一首歌曲填补字段

### Requirement: 完整性先于同步
系统 SHALL 获取全部页面并验证覆盖情况后才交付可提交快照。成功空歌单必须有明确的零条目依据。声明总数不符、分页中断、分页总数变化、重复页面或不明过滤均不得当作完整快照。来源有明确类型且可核对数量的非歌曲项可作为不支持条目报告；缺少可靠身份或无法解释的歌曲丢失须使本轮失败。

#### Scenario: 超过首页数量
- **WHEN** 歌单有超过 100 首歌曲
- **THEN** 获取完整分页或明确报告不完整，不将默认首页上限当作全部内容

#### Scenario: 非歌曲过滤
- **WHEN** 上游总数包含播客或本地不可用条目，而歌曲读取层只返回普通歌曲
- **THEN** 仅在所有原始位置已核对且排除项分类明确时交付歌曲快照并显示排除数量/原因；否则本轮不可提交

#### Scenario: 无法取全
- **WHEN** 网络失败、限制响应、未知总数且无其他完整性证明，或抓取达到保护上限
- **THEN** 保留上次已确认快照，不生成可信删除列表、不修改队列或本地成员状态

### Requirement: 获取边界与统一错误
所有歌单请求 SHALL 遵守当前网络门禁、取消、平台限流和有界请求/响应限制；鉴权、风控和限流不得通过更换接口或凭据绕过。绑定及刷新必须获取新快照，不以永久响应缓存伪装刷新。来源交付统一的输入、访问、受限、不完整、暂时失败、取消或运行环境不可用错误，业务不解释平台错误码。

#### Scenario: 禁网与取消
- **WHEN** 未满足应用出网条件，或用户取消正在抓取的歌单
- **THEN** 不启动新请求，终止等待/在途任务；已保存歌单仍可离线浏览

#### Scenario: 受限响应
- **WHEN** 上游报告限流或鉴权限制
- **THEN** 停止本轮，提供可重试时间或简短原因，不循环尝试匿名端点以规避限制
