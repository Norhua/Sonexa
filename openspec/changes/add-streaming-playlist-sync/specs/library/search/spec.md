# Spec Delta

## MODIFIED Requirements

### Requirement: 搜索范围
全部曲目、最近添加、普通歌单和标签页 SHALL 在右上角提供就地曲目搜索，占位文字说明范围；艺术家和专辑页相同位置仅查找名单。独立搜索页默认全库且仅含 in_library=true，不继承之前浏览页的集合条件。同步歌单可就地搜索当前歌单的已导入项，包括上游已移除的保留项，但不搜索未导入或忽略项，不因在同步页面搜索而扩大资料库范围。

#### Scenario: 歌单搜索
- **WHEN** 用户在普通或同步歌单内输入搜索词，再进入搜索页选择资料库
- **THEN** 歌单内结果限于当前歌单可见项，搜索页结果覆盖已入库曲目，不包含未入库同步曲目

### Requirement: 全文与高级条件
全文搜索 SHALL 覆盖曲名、署名、歌集名和关联艺术家。搜索页高级面板可逐项添加曲名、艺术家、专辑、标签；文本条件按对应字段包含匹配并取交集，空条件不参与。资料库搜索仅返回已入库曲目，未收藏的清单位置及同步专属曲目不进入结果；内部身份查询和导入判重不受此范围限制。

#### Scenario: 搜索完整 CV 署名
- **WHEN** 已入库曲目署名为涼宮ハルヒ(CV:平野綾)，用户检索任一侧文本
- **THEN** 可命中该曲目，不依赖拆分身份

#### Scenario: 管理高级条件
- **WHEN** 用户只添加艺术家条件或移除某条件
- **THEN** 仅使用仍有值的条件；全部留空返回已入库曲目，外部点击或 Escape 关闭面板

#### Scenario: 后台更新已提交查询
- **WHEN** 曲目字段、入库归属或标签改变，包括搜索页未显示时
- **THEN** 按最后一次成功提交的条件刷新资料库搜索结果，不采用未提交输入或高级条件草稿；较早响应不覆盖新查询
