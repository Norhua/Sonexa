# Spec Delta

## MODIFIED Requirements

### Requirement: 歌集与清单身份
具体发行 SHALL 以非空来源与发行标识唯一，本地发行名不唯一，组的多来源身份按发行组规格保存。清单属于具体发行，以碟号、音轨号定位，不依赖收藏曲目外键；仅同来源、同具体发行、同曲目标识且 in_library=true 算本版本已收藏。同录音在另一版本已入库可显示关联提示，但不算当前位置收藏。灰色行加入须携带来源、曲目和发行身份、名称、署名及位置等已知上下文，通过统一准入后建立关系；精确 track 已存在但未入库时复用它并显式入库。

#### Scenario: 相同录音的不同位置
- **WHEN** 库内曲目与清单位置录音相同但曲目标识或所属发行不同
- **THEN** 当前位置仍为灰色行，另行提示其他版本已收藏；删除部分收藏不改变仍保留发行的清单。合并展示按[浏览视图](../browse-views/spec.md)收敛行，不改变本版本收藏身份判断

#### Scenario: 灰色行加入
- **WHEN** 用户加入第二碟第一首灰色行并完成准入
- **THEN** 已入库曲目关联该具体发行并保存 2-1 位置、已知字段和来源，清单与组收藏计数一致更新；已有未入库精确曲目则复用，不创建副本

### Requirement: 代表发行
发行组 SHALL 仅将代表发行用于摘要封面或默认展开，不用其清单替代其他发行的收藏。音乐库展示代表仍可使用确定的展示偏好顺序，候选范围为组内至少有一首已入库曲目的发行；该顺序不参与自动导入选版。名单计数汇总全组已入库曲目，详情可看到每个已入库发行及其收藏。同步专属发行继续参与真实结构关系，但不竞争音乐库展示代表。

#### Scenario: 代表已无收藏
- **WHEN** 代表发行已无已入库曲目而同组其他发行仍有已入库曲目
- **THEN** 从仍有已入库曲目的成员重新确定展示代表；旧发行有同步曲目引用则保留，无任何 track 引用才清理，其他发行的收藏和计数不受影响
