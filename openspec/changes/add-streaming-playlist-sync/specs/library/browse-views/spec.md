# Spec Delta

## MODIFIED Requirements

### Requirement: 艺术家名单与角色筛选
艺术家名单 SHALL 仅根据已入库曲目包含署名成员和实际演唱者；未署名的纯作曲、作词、编曲者不因该角色进入名单。进入艺术家后显示其署名与全部角色的已入库曲目并集，角色筛选提供全部、署名及展示角色的去重计数，不把同步专属曲目的角色关系计入音乐库名单或分面。

#### Scenario: 署名作者和演唱者
- **WHEN** 已入库曲目署名 DECO*27，实际演唱为初音ミク，另有未署名编曲者
- **THEN** 前两者进入名单；DECO*27 不被标为演唱，编曲者仍可通过其关联已入库曲目查询

#### Scenario: 同步专属艺术家
- **WHEN** 一位艺术家只关联尚未入库的同步曲目
- **THEN** 不出现在音乐库艺术家名单及角色计数中，原始角色关系仍保留供详情和后续入库使用

### Requirement: 专辑分组与出现条件
专辑名单 SHALL 按本地发行组聚合，至少包含一首已入库曲目的组才展示；所有具体发行均有本地组，无发行关联的已入库曲目仍在曲库可见但不进入专辑名单。组标题与艺术家可为空，使用展示占位而不写造数据。组收藏数按全部成员中已入库曲目的本地身份计数，库内发行成员数只计至少一首已入库曲目的发行，与上游版本数分别标示；不同版本的总曲数不相加为组总曲数。同步专属引用可以保留本地发行，但不使它进入音乐库名单。

#### Scenario: 多版本收藏
- **WHEN** CD 与数字版同组且各有已入库曲目，包括同一录音的不同收藏
- **THEN** 名单合为一项，汇总所有已入库曲目且不按录音去重，详情能看到两个发行

#### Scenario: 本地歌集与删除
- **WHEN** 本地组有三首已入库曲目或最后一首被移出音乐库
- **THEN** 前者显示收藏数并按已知发行数据展示总数，后者退出名单；仍有同步引用的发行保留但不计入在库版本数，无任何曲目引用的发行才按存储清理规则删除

### Requirement: 专辑详情
专辑详情 SHALL 在组内有多个已入库发行时提供“合并 group / 拆分 group”切换并记住展示模式，不再提供顶部“仅显示已有”开关。拆分模式只为至少有一首已入库曲目的具体发行分区，各区使用自己的当前值、事实、封面、年份、碟数、每碟曲数与清单状态，并在区内按碟号、音轨号排序；各分区独立展开或收起清单，合并模式有独立清单展开控件。所有已入库曲目始终可见，完整清单可展开未入库位置的灰色行，不完整时显示已入库曲目及补全/重试；同步专属 track 不因存在本地 ID 而作为已收藏行显示。本地发行可展示用户填写的总数但不生成虚构灰色行。仅当所属发行清单完整且确无该曲目时提示清单外曲目，不能用代表发行清单判断其他版本异常。

#### Scenario: 清单加载
- **WHEN** 展开不完整的上游发行
- **THEN** 先展示该发行已入库曲目，再按策略尝试补取；失败显示错误与重试，其他发行的已入库曲目仍可见

#### Scenario: 仅显示已有
- **WHEN** 用户收起当前分区或合并视图的清单
- **THEN** 该范围只显示已入库曲目，展开恢复灰色行；此操作不再由全局“仅显示已有”开关控制

#### Scenario: 记住合并展示模式
- **WHEN** 用户选择合并或拆分 group 后切换专辑或重启
- **THEN** 保留展示模式，仅在多个已入库发行时显示切换入口；展开合并清单按需补取组内已入库发行，不遍历上游全部版本或同步专属发行

#### Scenario: 独占曲目
- **WHEN** White Love 仅入库于 SACD 发行，而展示代表为数字发行
- **THEN** 在 SACD 分区正常展示 White Love，不隐藏或标记为代表清单外异常

## ADDED Requirements

### Requirement: 展示合并不得扩大曲库范围
专辑合并、标签筛选、选择数和批量操作 SHALL 在已入库曲目集合上执行；同步专属曲目不进入合并行的可操作本地 ID 集合。后端保留的全部发行成员仍用于结构准入和编辑影响检查，不以音乐库展示过滤删减真实引用关系。

#### Scenario: 两种归属同录音
- **WHEN** 同一展示歌曲对应一个已入库 track 和一个同步专属 track
- **THEN** 曲库选择、普通歌单、删除和导出只包含已入库 ID，同步引用不会被合并操作暗中入库或删除
