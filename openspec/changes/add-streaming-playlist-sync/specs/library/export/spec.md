# Spec Delta

## MODIFIED Requirements

### Requirement: 格式与范围
曲库曲目右键菜单 SHALL 提供导出选中项、当前列表和全库。格式使用设置中的 CSV 或 JSON；选中项无有效已入库曲目时不可导出。所有既有导出范围均只包含 in_library=true，即使请求直接携带本地曲目 ID 也在服务端过滤；全库不等于整个 track 表。搜索页当前列表按已展示结果的标识快照取数。本期同步页面不新增独立歌单导出入口，不能借普通导出绕过入库范围。

#### Scenario: 导出搜索结果
- **WHEN** 资料库搜索显示 14 首，用户导出当前列表
- **THEN** 导出仍有效且已入库的这 14 首，不使用之前浏览页的过滤条件

#### Scenario: 选中项与灰色行
- **WHEN** 用户在专辑中多选并导出
- **THEN** 前端按曲目去重并排除灰色行，后端忽略已不存在或已取消入库的曲目；没有可导出项时提示原因

#### Scenario: 全库与同步专属曲目
- **WHEN** 数据库有十首已入库曲目和二十首同步专属曲目，用户导出全库
- **THEN** 只导出十首；显式提交未入库曲目的 ID 也不能使它进入既有导出
