# Spec Delta

## MODIFIED Requirements

### Requirement: 上游设置
上游分组 SHALL 从元数据注册表列出来源，专属表单按来源提供。MusicBrainz 包含联系方式、服务器地址与默认 1 请求/秒；iTunes 包含默认地区与默认 20 请求/分钟；QQ 音乐的速率与校验遵循本规格“QQ 合计请求速率设置”，说明该值合计约束元数据、封面查询、歌词和公开歌单请求，数值边界不因新能力改变。QQ 使用非公开接口，遇到风控或鉴权提示时报告不可用。另提供元数据来源优先顺序，默认为 musicbrainz、itunes、qq；仅有封面、歌词或歌单能力的来源不因此成为元数据选项。MusicBrainz 联系方式为空时，受检查的出网操作包括歌单读取均返回统一原因和设置入口信息。

#### Scenario: 填写联系方式
- **WHEN** 用户填写联系方式并保存
- **THEN** 前端重新读取出网状态，搜索、导入和歌单读取可使用，无需重启

#### Scenario: 共享配额说明
- **WHEN** 用户打开 QQ 音乐设置
- **THEN** 看到同一个速率值约束元数据、封面查询、歌词和公开歌单请求的说明，不出现独立 QQ 歌单或封面速率控件，不把图片下载计入该值

### Requirement: 主题与来源说明
主题 SHALL 按用户选择立即设为亮色或暗色，并从 localStorage 同步读取启动偏好；保存设置时回写当前主题，取消设置不回滚已切换主题。关于页显示版本及 MusicBrainz、Cover Art Archive、Apple/iTunes、QQ 音乐和网易云音乐的来源说明与链接；iTunes 说明不再要求按日期短期留存，仍保留图片不随导出分发的说明；QQ 音乐说明部分元数据、歌词、封面及公开歌单来自其非公开接口，歌词与封面图片不随导出分发。增加 Spotify 公开歌单来源、非官方读取依赖与随附运行环境的版本/许可说明，不要求账号或密钥，不声称已经作出服务条款合规结论。

#### Scenario: 重选主题
- **WHEN** 暗色状态下再次选择暗色并保存
- **THEN** 保持暗色，配置记录与界面一致

#### Scenario: 新封面来源与说明
- **WHEN** 用户打开关于页
- **THEN** 可识别四个封面来源及 MusicBrainz、iTunes、QQ 音乐三个元数据来源，QQ 音乐说明包含歌词与歌单，Spotify 标为公开歌单能力；不再看到 iTunes 保存天数或不得长期留存的要求

#### Scenario: 无需配置 Python
- **WHEN** 用户首次使用 Spotify 歌单能力
- **THEN** 不要求填写 Python 路径或安装命令，运行环境不可用时提供明确错误而不是伪装为空歌单
