## 真实追问、选项、选择及判断

- 本轮没有向用户发起追问，没有选项选择，不虚构用户对实现细节的确认。
- 用户明确授权：评估第 2 条合理后可直接执行。
- 助手判断：作为**通过原有匹配与歧义检查之后的选版偏好**合理；发行存在不是歌曲身份或版本正确的充分证据，不能在搜索结果中看到已有发行就无条件导入。
- 已向用户说明执行顺序：高置信/非 ReviewOnly 和三字段精确优先 → 同组、同曲目、同发行位置消歧 → 本地已有发行优先 → 必要的总曲数/国家/稳定身份比较 → 统一准入及提交重验。已有发行范围从仅音乐库扩展到所有本地 track 引用的发行，包含同步专属；同发行 CD/DVD 不同录音、跨组等仍复核。
- 已向用户说明标记按同来源精确 release / 原生 release group 身份查询，不把名称相同当“已存在”。
