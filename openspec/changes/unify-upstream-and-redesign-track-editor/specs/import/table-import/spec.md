## MODIFIED Requirements

### Requirement: 预览、提交与统计
向导 SHALL 预览前 20 行，分别统计字段缺失提示与真正空行或无法解析等跳过原因。具有有效映射数据但缺曲名、艺术家或专辑的行仍可提交，不因基本信息缺失跳过；完全空白的数据行不创建收藏任务。提交使用预览参数并保留原始行，关闭向导后启动 MusicBrainz 流程；可检索性不足的行进入复核。进度分母为实际入队数。

#### Scenario: 有跳过行
- **WHEN** 214 行中有 3 行完全空白，其余 211 行包括缺曲名但有其他有效映射数据的行
- **THEN** 211 行均入队，进度可达 211/211，缺曲名只提示字段缺失，3 行空白另列跳过原因
