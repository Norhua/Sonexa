# 2：已入库重复识别改为分层证据判定

## 原始提示词

```text
对于已入库重复的修改存在问题:
1. 如图/Users/amadeus/Library/Application Support/com.raycast.macos/clipboard/file-fdffaf6c14b2c9d8b962642f9e19ae89.png，这首歌只有一个结果，且已经入库但是还是出现在了复核队列
2. 如图/var/folders/xn/y6srybn90cv5cgpkv24s11_40000gn/T/pi-clipboard-1a05e351-82e2-4343-9c27-20a54d9cf0d8.png，首歌在库中虽然上游不是默认的MB但是也应该排除
3. 同样，以上都是问题的具体表现，而不是一种特殊情况， 请你找出根本原因然后修复

这些问题说明我前面说的"通过判断曲名和专辑名(在去掉翻译，注音等干扰项后)是否相同"的条件过于简单，请你设计新的方案
```

## 追问、选项与选择

本轮无新增追问或选项；沿用上一轮用户选择：候选行仅接受/跳过，其他条目动作保留。不引入 OpenSpec change，维护共享 spec-diff，不修改主 spec。

## Review 与根因

1. Tetra.：截图输入 `Tetra. / 原田瞳(原田ひとみ) / LINES`，库中专辑 `Trinoline Original Soundtrack ~LINES~`；本地徽章已经证明候选上游 track 绑定命中，但 `importMatchesTrackTx → SameTrackContext` 仍要求输入与当前曲名/专辑双精确，合理专辑简称被否决。Runner 又将 ExistingTrackID 转为 ambiguous，因此只有一条候选仍复核。
2. ツバサ：`ResolveImport` 仅扫描 `match_source IS NULL` 的本地曲目，其余只查本轮默认 MB 返回的来源/标识。QQ 已有收藏被查询范围排除；MB 无结果时完全没有机会认出它。
3. 去重发生在 MB 搜索后，导致本地已有的完整输入仍要依赖网络成功；失败时也不能排除重复。
4. 原始输入虽被保存，但成功接受/跳过的“输入 → 收藏”关系未作为有效、可失效的判定证据复用。用户改名或上游补全也不应天然抹掉已确认关系。
5. 条目进入复核后只重算候选徽章，不重新判断条目是否仍有必要留在复核，库中变化或规则修复无法消除已确认的冗余待办。

## 新方案（修改前设计）

- 业务判据置于 matching 的纯函数；store 负责读取全库事实、候选精确身份、历史关联、唯一性及事务提交。不加入 provider 名称分支，不调用其他上游弥补本地索引缺失。
- **证据分层**：有效历史确认关系 → 全库三字段严格等价 → 精确 track 绑定 + 多字段上下文（允许可靠专辑简称）；每条输入都必须支持同一唯一目标。多个候选或多个库内目标不得仅因“其中一个已在库”就任选一个。
- **全库检查**：含所有已绑定来源与本地收藏；优先离线识别，不依赖 MB 查得到。曲名、完整署名、专辑均严格一致可确认；时长、位置、版本等冲突为否决，不因字段缺失加分。
- **简称受限**：曲名严格、艺术家可靠一致、候选精确绑定才允许专辑完整词边界的包含关系，不使用 Jaro-Winkler 或任意子串当同 track 依据。泛称（Album/Single/Soundtrack 等）不作为简称；Live/Remix/豪华版/重制等版本差异仍保护。
- **快照与当前值**：使用身份仍与 track 和具体 release 绑定一致的快照作为完整另一份比较事实，不能跨两份资料各挑有利字段拼凑证据；当前值用于用户输入匹配，快照用于保持上游身份。历史关联按删除/换绑/位置变化失效，不因封面/歌词等无关修改失效。
- **可追溯关联**：成功接受、明确跳过与自动排除均同事务保存输入关系及依据，包含被合并输入。使用独立表及 FK/身份变更失效保护，不借旧行号或文件路径识别；历史有冲突时保留复核。
- **状态机一致**：导入前置检查、检索后检查、自动准入并发重验使用相同证据函数。复核读取前对未手工改搜的 review/failed 条目做离线一致性整理，不用手改搜索条件自动处置原始输入；终态、手工请求序号与事务原子性继续保护。
- **显示职责不变**：跨来源判定只结束重复导入，不替换库中主上游、不伪造另一个候选已绑定；ISRC/recording 仍不是 track 绑定。

## 验证目标

复现两张截图；无 MB 结果/MB 请求失败时 QQ 收藏仍离线排除；通用简称和异写；不同艺术家、版本、专辑、位置、时长及多个同名目标保留；历史接受/跳过可复用但删除/换绑不误用；真实 App 入口、并发准入与复核整理均有回归。
