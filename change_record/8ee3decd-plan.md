# 编辑页专辑信息保存方式修复计划

- 起始提交：`8ee3decd8a058975c18044960f4af0b8a13facc8`
- 日期：2026-10-06
- 背景：测试阶段允许在保留上游绑定的情况下修改专辑资料。本次只修改实现及 `change_record`，不修改任何 OpenSpec 文档。

## 修改计划

1. 专辑改动提示提供“新建专辑信息 / 修改专辑信息 / 取消”三个按钮，说明原地修改会更新当前专辑关联歌曲共享的资料，取消保留草稿。
2. 保存草稿显式区分新建与修改。未切换发行上游时，修改原专辑字段和封面，保留发行、歌曲绑定及收藏关系；新建仍创建无上游绑定的本地专辑并逐曲确认迁入。
3. 切换上游时仅允许新建，保留精确目标绑定，继续使用已有逐曲对应、复用目标值保护及成员准入流程。没有原专辑或显式解除发行绑定时，不提供不可成立的原地修改操作，并说明原因。
4. 原地修改沿用事务保存、字段来源判定、修订冲突及文件准备机制；检查共享歌曲位置与专辑结构的一致性，同步更新检索和浏览信息。
5. 在唯一的 `spec-diff.md` 中记录三个按钮、原地修改及与原规格强制新建规则的冲突。
