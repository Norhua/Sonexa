# 导入与复核问题

- 导入进度的分母是实际入队的原始行数，不因多个来源归为同一问题而减少。空行或无有效映射内容不入队；缺少基本信息仍可进入复核。
- 新增收藏与已存在跳过分列。待复核、失败等为原始行计数；未匹配是待复核子集，已存在跳过是跳过子集，不能重复相加。
- 侧栏徽标是全部批次的独立待处理问题数，悬停说明包含来源行数及待选/失败分项。跨批共享问题不能按批次问题数求和。导入队列列出每批关联问题数。
- 复核页按独立问题浏览。展开来源可查看文件、批次、数据行序号、原始字段、完整原始行（含未映射列）、失败及判断依据。数据行序号从 1 开始，不包含表头，不等同于含多行单元格文件的物理行号。
- 候选的分数是检索匹配程度，不是正确版本的概率。共享 ISRC/Recording 不代表同一个收藏 track；精确已收藏候选显示跳过，其余显示接受。
- 接受、跳过、改搜和无一匹配作用于当前展示的完整问题范围。一次接受最多新增一个 track，其余精确重复行记已存在跳过；跳过结束来源输入，不只是隐藏候选，也不修改已有收藏。
- 来源下拉选择候选事实及单行操作对象。无需匹配只保存该行原始已知值，移出/拆出只作用于该行；失败重试只处理界面列出的失败成员。
- 确认弹窗显示输入范围。取消保留草稿与范围；新增来源或证据变化后旧操作禁用，刷新队列并查看新范围后重新确认。可以先拆出某一行，再独立改搜。
- 打开问题时获取短期交互保护，草稿、改搜和确认期间暂缓后台自动结束。切换/离开释放；续约只延长期限，不轮询资料。保护失效时操作禁用，刷新可重新打开且保留草稿。
- 任务/复核变更会刷新统计，即使没有导入正在运行或计数不变；收藏变化只在本地重算候选状态，不因打开页面重复联网搜索。失败刷新保留内容，明确显示错误并允许重试。

浏览器自动化使用 Wails 替身；真实身份、事务、跨批归并与租约保护由 Go App/Runner/Store 测试验证。浏览器测试不代表已完成原生 Wails 或真实来源网络验收。
